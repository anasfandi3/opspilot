# OpsPilot

OpsPilot is a multi-tenant workflow and approval management platform built with Laravel and Vue.

It allows organizations to create internal workflows, submit requests, assign approval steps, and track decisions across teams.

## Planned Features

* Multi-tenant organization support
* Configurable workflows and approval steps
* Request submission and status tracking
* Role-based permissions
* Approval and rejection handling
* Activity and audit logs
* Notifications and queued jobs
* Admin dashboard

## Tech Stack

* Laravel
* Vue 3
* TypeScript
* Tailwind CSS
* MySQL
* Redis
